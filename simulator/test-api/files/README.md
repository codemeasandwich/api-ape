# Files Controllers Module

## Overview

The files module provides test controllers for binary file transfer functionality. These controllers handle file upload and download operations.

**Key capabilities:**

- **File upload** — Receive binary data from clients
- **File download** — Send binary data to clients

These controllers test api-ape's binary transfer system including tagging and HTTP data endpoints.

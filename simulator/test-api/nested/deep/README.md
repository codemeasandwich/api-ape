# Deep Nested Controllers Module

## Overview

The deep module provides additional nesting levels for testing api-ape's path resolution at depth. Contains both index mapping and direct handler files.

**Key capabilities:**

- **Deep index** — Test `index.js` at 2 levels deep
- **Handler files** — Test non-index files at depth
- **Very deep** — Test 4-level deep routing

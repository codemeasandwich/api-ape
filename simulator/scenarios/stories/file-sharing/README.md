# File Sharing Stories Module

## Overview

The file sharing stories module contains test suites for api-ape's binary file transfer functionality. These tests verify upload, download, and client-to-client file sharing.

**Key capabilities:**

- **File upload** — Test binary data upload to server
- **File download** — Test binary data download from server
- **Client-to-client** — Test file sharing via broadcast
- **Large files** — Test handling of larger file transfers

These stories exercise `fileTransfer.js`, binary tagging, and HTTP data endpoints.

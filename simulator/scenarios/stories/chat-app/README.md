# Chat App Stories Module

## Overview

The chat app stories module contains complete user journey tests simulating a real-time chat application. These tests combine multiple api-ape features into realistic scenarios.

**Key capabilities:**

- **Complete user journey** — Full chat session with multiple users
- **Real-time messaging** — Rapid message exchange between users
- **Room scaling** — Many users in a chat room simultaneously

These stories exercise the full api-ape stack in a realistic application context.

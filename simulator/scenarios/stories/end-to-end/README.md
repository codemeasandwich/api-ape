# End-to-End Stories Module

## Overview

The end-to-end stories module contains comprehensive test suites covering cross-feature scenarios and edge cases. These tests ensure api-ape works correctly in complex real-world situations.

**Key capabilities:**

- **Async operations** — Test async controllers and parallel calls
- **Binary data** — Test binary data edge cases
- **Broadcast edge cases** — Test broadcast to empty rooms, bursts
- **Complex data types** — Test JSS type preservation
- **Connection edge cases** — Test rapid connect/disconnect, failures
- **Error handling** — Test various error scenarios and recovery
- **High load** — Test performance under stress

These stories achieve thorough coverage of edge cases and error paths.

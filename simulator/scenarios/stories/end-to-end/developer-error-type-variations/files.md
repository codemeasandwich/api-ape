# Error Type Variations Test Scenario Files

Tests different error types and their properties.

## Directory Structure

```
developer-error-type-variations/
├── custom-error-with-code-property-propagates.js
└── validation-error-with-field-info-propagates.js
```

## Files

### custom-error-with-code-property-propagates.js

Tests that custom errors with additional details like field names propagate to the client.

### validation-error-with-field-info-propagates.js

Tests that validation errors with field information are received by the client.

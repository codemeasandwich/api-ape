# Data Type Edge Cases Test Scenario Files

Tests edge cases for data type handling.

## Directory Structure

```
developer-data-type-edge-cases/
├── arrays-of-complex-types-round-trip.js
├── deeply-nested-data-preserved.js
└── empty-and-null-values-handled-correctly.js
```

## Files

### arrays-of-complex-types-round-trip.js

Tests that arrays containing complex types like Date are preserved through round-trips.

### deeply-nested-data-preserved.js

Tests that deeply nested plain objects (5+ levels) are preserved through API calls.

### empty-and-null-values-handled-correctly.js

Tests that empty objects, null values, empty arrays, and empty strings are handled correctly.

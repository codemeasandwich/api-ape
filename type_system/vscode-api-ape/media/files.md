# Media Assets

Icons and images for the VS Code extension UI.

## Directory Structure

```
media/
├── files.md               # This file
├── completionitemkind.png # Reference image for completion item kinds
├── endpoint-icon.svg      # Icon for API endpoints in tree view
├── insert-icon-dark.svg   # Insert action icon (dark theme)
├── insert-icon-light.svg  # Insert action icon (light theme)
├── sidebar-icon.svg       # Extension sidebar icon
└── status-icon.svg        # Status bar icon
```

## Files

### `completionitemkind.png`

Reference image showing VS Code completion item kind icons.

### `endpoint-icon.svg`

SVG icon displayed next to API endpoints in the explorer tree view.

### `insert-icon-dark.svg`

Insert action icon for dark theme contexts.

### `insert-icon-light.svg`

Insert action icon for light theme contexts.

### `sidebar-icon.svg`

Icon displayed in the VS Code activity bar for the extension.

### `status-icon.svg`

Icon displayed in the VS Code status bar.

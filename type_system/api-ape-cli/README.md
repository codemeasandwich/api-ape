# @api-ape/cli

Command-line tool for generating TypeScript types from api-ape controllers.

## Overview

The `api-ape-types` CLI analyzes your api-ape controller files and generates TypeScript declaration files, enabling IntelliSense, type checking, and autocompletion in your IDE - all without requiring a running server.

## Installation

### Global Installation

```bash
npm install -g @api-ape/cli
```

### Local Installation (Recommended)

```bash
npm install --save-dev @api-ape/cli
```

### Using npx

```bash
npx @api-ape/cli --controllers ./api --output .api-ape
```

## Quick Start

1. **Generate types from your controllers:**

```bash
api-ape-types --controllers ./api --output .api-ape
```

2. **Add the output to your tsconfig.json:**

```json
{
  "include": ["src/**/*", ".api-ape/**/*"]
}
```

3. **Enjoy IntelliSense in your code:**

```typescript
import api from 'api-ape';

// Full autocompletion and type checking!
const user = await api.users.profile({ userId: '123' });
```

## Usage

### Basic Usage

```bash
api-ape-types --controllers <path> [--output <path>] [--watch] [--verbose]
```

### Options

| Option | Alias | Description | Default |
|--------|-------|-------------|---------|
| `--controllers` | `-c` | Path to controllers directory (required) | - |
| `--output` | `-o` | Output directory for generated files | `.api-ape` |
| `--watch` | `-w` | Watch for changes and regenerate | `false` |
| `--verbose` | `-v` | Enable verbose output | `false` |
| `--version` | - | Show version number | - |
| `--help` | `-h` | Show help | - |

### Examples

**Generate types once:**

```bash
api-ape-types -c ./api -o .api-ape
```

**Watch mode for development:**

```bash
api-ape-types -c ./api -o .api-ape --watch
```

**Verbose output:**

```bash
api-ape-types -c ./api -o .api-ape --verbose
```

**Using with npx:**

```bash
npx @api-ape/cli -c ./api -o .api-ape
```

## Output Files

The CLI generates the following files in the output directory:

### `.api-ape/schema.json`

The raw schema data extracted from your controllers:

```json
{
  "version": "abc12345",
  "timestamp": 1705840800000,
  "controllersDir": "/path/to/api",
  "endpoints": [
    {
      "path": "users/profile",
      "filePath": "/path/to/api/users/profile.js",
      "line": 15,
      "column": 1,
      "description": "Get user profile by ID",
      "input": { "kind": "object", "properties": { ... } },
      "output": { "kind": "promise", "resolves": { ... } },
      "throws": ["Error: User not found"]
    }
  ],
  "channels": []
}
```

### `.api-ape/api-ape.d.ts`

TypeScript declarations that augment the `api-ape` module:

```typescript
// Auto-generated by @api-ape/cli
// Generated at: 2024-01-21T12:00:00.000Z
// Schema version: abc12345

import 'api-ape';

declare module 'api-ape' {
  interface UsersEndpoints {
    profile(data: { userId: string }): Promise<{ name: string; email: string }>;
    settings(data?: { theme?: string }): Promise<void>;
  }

  interface ApiEndpoints {
    users: UsersEndpoints & ApiEndpoints;
    chat: ChatEndpoints & ApiEndpoints;
  }

  const api: ApiEndpoints & { ... };
  export default api;
}
```

### `.api-ape/tsconfig.json`

Auto-generated tsconfig for the types (created only if it doesn't exist):

```json
{
  "compilerOptions": {
    "types": []
  },
  "files": ["api-ape.d.ts"]
}
```

## Integration with Your Project

### TypeScript Configuration

**Option 1: Include the directory**

```json
{
  "compilerOptions": { ... },
  "include": ["src/**/*", ".api-ape/**/*"]
}
```

**Option 2: Use triple-slash reference**

```typescript
/// <reference path="./.api-ape/api-ape.d.ts" />
```

**Option 3: Extend the generated tsconfig**

```json
{
  "extends": "./.api-ape/tsconfig.json",
  "compilerOptions": { ... }
}
```

### Package.json Scripts

Add convenient scripts to your `package.json`:

```json
{
  "scripts": {
    "types": "api-ape-types -c ./api -o .api-ape",
    "types:watch": "api-ape-types -c ./api -o .api-ape --watch",
    "prebuild": "npm run types",
    "dev": "concurrently \"npm run types:watch\" \"npm run start:dev\""
  }
}
```

### Git Configuration

Add to `.gitignore` if you prefer to generate on build:

```gitignore
.api-ape/
```

Or commit the generated files for faster CI/CD:

```gitignore
# Don't ignore - commit generated types
# .api-ape/
```

## Writing Controller Documentation

The CLI extracts type information from JSDoc comments. Here's how to document your controllers for best results:

### Basic Controller

```javascript
/**
 * Get user profile by ID
 *
 * @param {Object} data - Request data
 * @param {string} data.userId - The user's unique ID
 * @param {boolean} [data.includeStats] - Include usage statistics (optional)
 * @returns {Promise<{name: string, email: string, avatar?: string}>}
 * @throws {Error} User not found
 */
module.exports = async function(data) {
  const user = await db.users.findById(data.userId);
  if (!user) throw new Error('User not found');
  return user;
};
```

**Generated type:**

```typescript
interface UsersEndpoints {
  /**
   * Get user profile by ID
   * @endpoint /users/profile
   */
  profile(data: {
    /** The user's unique ID */
    userId: string;
    /** Include usage statistics (optional) */
    includeStats?: boolean;
  }): Promise<{
    name: string;
    email: string;
    avatar?: string;
  }>;
}
```

### Complex Types

```javascript
/**
 * Create a new order
 *
 * @param {Object} data
 * @param {string} data.customerId - Customer ID
 * @param {Array<{productId: string, quantity: number}>} data.items - Order items
 * @param {Object} [data.shipping] - Shipping details
 * @param {string} data.shipping.address - Shipping address
 * @param {string} [data.shipping.notes] - Delivery notes
 * @returns {Promise<{orderId: string, status: 'pending' | 'confirmed', total: number}>}
 */
module.exports = async function(data) {
  // Implementation
};
```

### No Parameters

```javascript
/**
 * Get server health status
 *
 * @returns {{status: 'healthy' | 'degraded', uptime: number}}
 */
module.exports = function() {
  return { status: 'healthy', uptime: process.uptime() };
};
```

**Generated type:**

```typescript
interface HealthEndpoints {
  (data?: any): Promise<{
    status: 'healthy' | 'degraded';
    uptime: number;
  }>;
}
```

## Watch Mode

Watch mode is ideal for development. It monitors your controllers directory and regenerates types whenever files change:

```bash
api-ape-types -c ./api --watch
```

**Features:**
- Debounced regeneration (100ms) to handle rapid saves
- Handles file additions, modifications, and deletions
- Graceful shutdown with Ctrl+C
- Error recovery - continues watching after errors

**Output:**

```
Generated types for 15 endpoints in 45ms

Watching for changes in: /path/to/api

Changed: /path/to/api/users/profile.js

Regenerating types...
Generated types for 15 endpoints in 32ms
```

## Programmatic Usage

You can also use the CLI functionality programmatically:

```javascript
const { generateSchema, generateTypes } = require('@api-ape/cli');
const path = require('path');
const fs = require('fs');

// Generate schema
const controllersDir = path.resolve('./api');
const schema = generateSchema(controllersDir);

// Generate TypeScript declarations
const types = generateTypes(schema);

// Write to files
fs.writeFileSync('.api-ape/schema.json', JSON.stringify(schema, null, 2));
fs.writeFileSync('.api-ape/api-ape.d.ts', types);
```

## Troubleshooting

### "Controllers directory not found"

Ensure the path is correct and the directory exists:

```bash
# Wrong - relative path might not resolve correctly
api-ape-types -c api

# Correct - use explicit relative path
api-ape-types -c ./api
```

### Types not updating in VS Code

1. Run "TypeScript: Restart TS Server" command
2. Ensure `.api-ape/` is included in your `tsconfig.json`
3. Check that the file watcher is running (watch mode)

### Generated types have `any` everywhere

Add JSDoc documentation to your controllers:

```javascript
// Before - no types extracted
module.exports = function(data) {
  return data;
};

// After - full type information
/**
 * @param {{name: string, age: number}} data
 * @returns {{id: string, name: string, age: number}}
 */
module.exports = function(data) {
  return { id: generateId(), ...data };
};
```

### Watch mode not detecting changes

Check if your editor is saving to a temporary file first:

```bash
# Some editors save to .tmp files - add explicit extensions
api-ape-types -c ./api --watch --verbose
```

# Assets

Static assets for documentation and branding.

## Directory Structure

```
assets/
├── files.md           # This file
├── apiApeLogo.jpg     # api-ape logo
├── friend.jpg         # api-ape mascot image
├── icons.png          # Extension icon (standard)
├── icons_2.png        # Extension icon (variant 2)
└── icons_@.png        # Extension icon (high DPI)
```

## Files

### `apiApeLogo.jpg`

The api-ape logo used in server README header.

### `friend.jpg`

The api-ape mascot image used in the main README.

### `icons.png`

Standard resolution icon for the VS Code extension.

### `icons_2.png`

Variant 2 of the extension icon.

### `icons_@.png`

High DPI version of the extension icon for retina displays.

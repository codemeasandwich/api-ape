# LSP Providers

LSP feature provider implementations.

## Directory Structure

```
providers/
├── files.md       # This file
├── completion.js  # Completion provider
├── definition.js  # Go-to-definition provider
└── hover.js       # Hover provider
```

## Files

### `completion.js`

Provides intelligent completions for api-ape proxy chains.

### `definition.js`

Provides go-to-definition for navigating to controller files.

### `hover.js`

Provides hover information showing endpoint documentation.

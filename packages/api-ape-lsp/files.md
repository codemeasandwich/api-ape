# @api-ape/lsp

Language Server Protocol implementation for api-ape IntelliSense.

## Directory Structure

```
api-ape-lsp/
├── files.md       # This file
├── package.json   # Package configuration
├── README.md      # Documentation
└── src/
    ├── server.js       # LSP server entry point
    ├── analysis/       # Document analysis
    ├── providers/      # LSP feature providers
    ├── schema/         # Schema management
    └── utils/          # Shared utilities
```

## Files

### `package.json`

Package configuration for @api-ape/lsp npm package.

### `README.md`

Documentation for the LSP server features and configuration.
